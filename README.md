# Launchly Landing Page

A responsive multi-section landing page built with React, Vite, and modern component composition.

## Components
- **Header**: Navigation bar with logo and nav links.
- **WelcomeBanner**: Legacy class component managing local state for a dismissable notification banner.
- **Hero**: Main call-to-action banner with title, subtitle, and CTA button.
- **Features / FeatureCard**: Reusable cards displaying key product features.
- **Footer**: Dynamic copyright footer with the current year.
